# 导出与打印指南

SeatTrellis 使用本地 Rust 导出引擎渲染已保存的座位方案。生成文件无需安装 Microsoft Office、LibreOffice、Python 或无头浏览器；打开和打印文件仍需要支持对应格式的应用。耗时取决于座位图、格式和本机字体，首次加载字体可能较慢。

## 先生成、检查，再保存

工作台提供统一的导出页面：

1. 选择格式、姓名显示方式，以及该格式支持的页面设置。
2. 生成预览，检查姓名、座位编号、走道、方向和警告。
3. 保存已生成的文件。保存直接使用内存中同一份文件，不会悄悄重新生成另一版。

SVG 和 PNG 直接显示生成的图片；HTML 从实际生成的文件中提取内嵌 SVG 座位图，以不可执行脚本的图片方式预览，保存时仍写出完整原始 HTML，避免嵌入页面和 WebView 沙箱的兼容性问题。PDF 使用同一场景生成的 SVG 页面图预览，不依赖浏览器 PDF 插件；保存时仍写出已经准备好的实际 PDF 文件。Office 格式则同时准备可编辑文档，并根据同一方案和设置展示座位图预览。它**不是 Word、Excel 或 PowerPoint 的逐像素预览**。

修改设置、切换方案或编辑方案后，之前生成的文件会失效，需要重新预览。可以取消准备过程；遇到超时或方案版本过期提示时，应使用当前方案重试。浏览器下载与桌面保存对话框的行为不同，看到预览不代表文件已经写入磁盘。

## 格式与页面控制

工作台提供七种选择。旧的 `html` 格式仍兼容 CLI 和 API，但界面不再重复列出两个 HTML 选项。

| 格式 | 适用场景 | 工作台中的页面设置 |
| --- | --- | --- |
| 打印网页（`print-html`） | 可独立查看和浏览器打印的无脚本网页 | A4、A3 或 Letter；方向；页边距 |
| PDF（`pdf`） | 用于分享、打印的固定单页图像文档 | A4、A3 或 Letter；方向；页边距 |
| PNG（`png`） | 用于消息、演示软件的页面图片 | A4、A3 或 Letter；方向；页边距 |
| SVG（`svg`） | 可缩放座位图；存在受支持本机字体时，以字形轮廓固定外观 | A4、A3 或 Letter；方向；页边距 |
| Word（`docx`） | 可编辑的座位表文档 | A4、A3 或 Letter；方向；页边距 |
| PowerPoint（`pptx`） | 16:9 幻灯片上的可编辑座位形状与文字 | 固定幻灯片比例，不显示纸张设置 |
| Excel（`xlsx`） | 可编辑座位网格与座位分配明细工作表 | 工作表布局，不显示纸张设置 |

工作台默认使用打印网页、A4 横向和 12 mm 页边距。窄、宽页边距分别为 6 mm 和 20 mm。不使用纸张设置的格式会隐藏这些控件。

HTML、SVG、PNG 和 PDF 共用以磅为单位的场景布局，座位比例、编号、空隙和文字位置来自同一模型。座位图整体适配所选页面，不单独拉伸每张座位。PNG 和 PDF 以 216 dpi 栅格化该场景；PDF 文字属于页面图像，不能作为文字选中。存在可用本机字体时，SVG/HTML 将字形转换为路径，其他电脑无需安装同一字体即可显示这些轮廓。需要继续编辑姓名时，请使用 Office 格式。

Office 文档使用原生表格、单元格或形状，不将所有内容压成图片。阅读器可能替换字体或以不同方式排列可编辑文字。分发或打印前，请在实际使用的应用中检查文件。

## 姓名与隐私

工作台默认导出真实姓名，**学号默认关闭，需要主动开启**。选择匿名标签后，姓名替换为编号占位文字，同时隐藏学号和个人明细行。

导出页面不提供成绩、备注、特殊需求、身高或视力开关；工作台请求不会加入这些个人明细，也没有提供带额外分析的独立报告模板。

匿名化处理的是学生字段，不会自动识别班级标题或座位编号中手工输入的个人信息。分享前请自行检查这些内容。保存文件会产生由你管理的副本：更改设置、取消准备或离开页面，都不会安全擦除已保存文件、下载内容或操作系统副本。更广泛的数据处理边界见[隐私指南](privacy.md)。

## 警告与打印检查

- **没有可用的本机字体：** PNG/PDF 可能生成不含文字的文件并给出警告。不要将其当作完整座位图分发。SVG/HTML 可能回退到阅读器字体，此时外观不再由字形路径固定。
- **不支持的字符：** 所选字体可能缺少生僻姓名用字。警告只统计不同缺失字符的数量，不包含姓名。请检查预览；可编辑 Office 文档可能通过另一种已安装字体正确显示这些字符。
- **文字过小或被缩短：** 座位过密或字段过长可能导致小字号或省略号。请尝试更大纸张或更合适的方向。如果完整内容比单页座位图更重要，可查看 Excel 的座位分配明细工作表。

使用浏览器打印时，请检查打印预览，选择正确纸张，并关闭额外页眉、页脚。HTML 已包含页面边距，应避免浏览器再次增加一套边距。打印机硬件、缩放设置和阅读器行为仍会影响结果，不能保证每台打印机输出完全相同。

## CLI 兼容性

原有 `export` 和 `project-export` 命令继续可用，渲染前会校验求解后的分配方案。`project-export` 读取已保存快照，不重新求解。

```bash
seattrellis export \
  --problem problem.json \
  --solution plan.json \
  --format png \
  --output outputs/plan.png

seattrellis project-export \
  --project my-class/seattrellis.project.json \
  --snapshot outputs/candidates.json \
  --candidate candidate_02 \
  --format print-html \
  --template public \
  --orientation landscape \
  --output outputs/class_wall.html
```

`--template teacher` 保留真实姓名，`--template public` 匿名化学生字段。旧 `project-export` 的教师版还包含学号及已有的身高、视力明细，与工作台默认值不同。它的 `--orientation auto` 使用渲染器默认方向：`print-html` 横向，其他纸张格式纵向；PPTX 始终为 16:9。请通过各命令的 `--help` 核实支持的参数，不要假设所有工作台设置都有同名 CLI 参数。

兼容 API 继续接受 `html`、`page_scale` 等旧字段，但将座位图放大到页面之外并非受支持的裁切功能：超过适配比例的值不会刻意把座位推到纸外。新工作台使用自动适配，不再提供独立缩放滑块。
