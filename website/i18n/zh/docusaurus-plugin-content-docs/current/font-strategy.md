# 字体渲染与排版

SeatTrellis 使用已经安装的字体，不下载或捆绑字体文件。需要区分两类输出：导出时固定外观的座位图，以及在其他应用中保留可编辑文字的文档。

## 各格式如何使用字体

| 输出 | 字体行为 |
| --- | --- |
| PNG / PDF | 使用所选本机字体，以 216 dpi 栅格化共用页面场景。阅读器不会替换图像里的字体；PDF 文字不可选中。 |
| SVG / HTML / 打印网页 | 有受支持的本机字体时，显示的文字转为字形路径，与 PNG/PDF 使用相同字体面。查看文件的电脑无需安装该字体。没有可用本机字体时，浏览器字体回退可能改变外观。 |
| XLSX / DOCX / PPTX | 文字保持可编辑。文件声明字体，但阅读器可能替换为已有字体，改变换行、对齐或分页。工作台预览展示座位图，而不是最终 Office 阅读器的渲染结果。 |

SVG 文字轮廓与 PNG/PDF 字形共用所选字体面和字符推进宽度；页面坐标和字号均以磅计量。统一这些度量，避免预览和下载文件独立排版产生错位，但不会消除打印机页边距、阅读器缩放或应用自身打印行为的影响。

工作台使用 SVG 预览 PDF 的页面场景，不依赖浏览器 PDF 插件。保存下载的是准备好的 PDF，而不是预览用的 SVG。

## 字体发现与字体面选择

引擎按固定顺序检查已知文件及其准确的 PostScript 字体面名称：

1. 苹方简体常规（`PingFangSC-Regular`）。
2. Noto Sans CJK SC Regular（`NotoSansCJKsc-Regular`）。
3. 微软雅黑（`MicrosoftYaHei`）。
4. 黑体简体 Medium（`STHeitiSC-Medium`）；受支持的 macOS 字体面虽然名称含 Medium，实际正常字重为 400。
5. 文泉驿正黑（`WenQuanYiZenHei`）。
6. Arial Unicode MS（`ArialUnicodeMS`）。
7. 中易宋体（`SimSun`）。

实际选择取决于操作系统和字体安装情况。在转向低优先级字体族之前，也会检查受支持的用户安装位置。因此，用户安装的首选字体可以优先于系统中的旧式后备字体。

`.ttc` 文件包含多个字体面。SeatTrellis 读取名称，选择目标正常字重简体中文字体面，将其真实集合索引交给栅格化器；不会假设索引零就是正确字体面，也不会将 Heiti Light 文件冒充苹方。

不可读取、损坏、字体面不匹配或不适用的候选会被跳过。常用中英文字形检查可以排除明显不适用的字体，但不能保证覆盖每个生僻姓名用字。成功选中的字体会在进程内缓存；查找失败后冷却一秒再允许重试，避免测量文字时重复扫描文件系统。失败结果不会永久缓存，因此安装受支持字体后可以恢复后续导出。更换已成功选中的字体后，应重启 SeatTrellis 以清除成功缓存。

## 安装与自定义字体边界

无图形界面的 Linux 环境应确保运行 SeatTrellis 的进程能读取受支持的 Noto Sans CJK SC Regular 字体。仅在浏览器所在电脑安装字体，不会将其提供给另一台服务器或容器。

字体发现并非通用的操作系统字体选择器。安装任意学校专属字体、楷体变体或自定义 `.ttf`/`.otf`，**不会**自动让 SeatTrellis 使用它。当前导出页面没有自定义字体选择功能。需要为可编辑文档指定另一种字体时，请打开 Office 导出文件，在文档应用中更换字体并重新检查排版。

已知文件路径和字体面名称见实现文件 `crates/seattrellis-export/src/fonts.rs`。SVG/HTML 不包含字体文件，只包含该座位图所用文字的绘制路径。字体安装与使用者仍需自行遵守字体授权条件。

## 文字问题排查

- **PNG/PDF 没有文字：** 查看“没有可用字体”警告，并安装受支持字体。文件成功写出不代表其中一定有文字。
- **出现方框或生僻字缺失：** 查看缺字警告。警告只统计不支持的字符数量，不复述学生姓名。字体加载成功不等于支持全部语言字符。
- **姓名太小或被缩短：** 查看小字号、文字缩短警告，调整纸张和方向，或使用可编辑分配明细工作表查看完整内容。
- **Office 与座位图预览不同：** 检查阅读器已安装字体、缩放和打印设置。本机导出字体警告描述 SeatTrellis 自己完成的渲染；Office 阅读器自行选择字体。
- **SVG/HTML 换设备后外观不同：** 检查导出时是否没有可用本机字体，因而输出了回退文字而非固定字形路径。

请始终检查已生成的预览；可编辑格式还应在实际阅读器中核验。本机栅格化与字体回退都不意味着支持所有文字系统，也不保证所有打印机输出相同。
