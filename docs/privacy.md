# 隐私说明

SeatTrellis 默认完全在本机处理数据，不包含账号、云同步或遥测。

## 数据边界

- 不要把真实学生名单、成绩、备注、特殊需求或历史 snapshot 提交到公开仓库。
- `outputs/`、`exports/`、`snapshots/`、`private/` 和 `data/` 已被 Git 忽略。
- Project 文件只保存路径和默认设置，不嵌入引用文件。
- 分享截图、Issue 或导出文件前应删除所有可识别信息。
- `examples/` 只能包含虚构人物和虚构班级。

公示版导出默认只展示姓名和座位。教师内部版可能包含敏感字段，应保存在受控设备和目录中。
