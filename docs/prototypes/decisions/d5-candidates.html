Decision D5 · 计划 §7.7

候选方案比较：表格 / 雷达图 / 差异高亮 / 逐规则列表

真实任务：系统为「初二（3）班」生成 5 个候选，推荐方案 A（总分 84.4）。教师需要回答四个问题：① 为什么推荐 A？② A 与 B 的主要 objective 差异？③ 硬规则是否全部满足？④ 两个方案在座位分配上差多少？

数据契约（§7.7，冻结中）：比较数据来自 Rust 的 PlanScore（七维 + rule_scores + hard_constraint_summary）与 candidate distance 去重信息；「表格、雷达图、差异高亮、逐规则列表」的呈现方式正是本决策要冻结的对象——最终以理解速度与误读率（可用性记录）为准。

代价维度多时横向拥挤；「为什么推荐 A」需要额外解读规则说明；教师可能被无关维度干扰。

雷达图回答「形状差异」最快；数值精确性低于表格——需要 hover/点击显示数值（本演示为静态）。
优势一眼看出「A 在公平轮换/稳定性更强，B 在成绩混合更强」；视觉记忆性好；适合演示与分享。
代价维度多时蜘蛛网难以阅读；颜色区分对色弱用户不友好（需形状+文字双编码）；精确数值需二次操作；实现成本最高。
