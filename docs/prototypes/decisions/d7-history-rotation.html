历史 / 轮换模型 — 融合方案：历史回顾（时间线）+ 轮换计划 双视图

真实任务不变：教师回答「上期谁坐谁旁边」「这期为什么这样轮换」，并把 4 期轮换一起生成、批量保存。回顾（时间线）与规划（周期计划）是两种心智模型，双视图切换各自清晰；「恢复此版本」入口保留在时间线节点（数据安全能力不因 UI 形态移除）。

不可违反约束：轮换由 Rust 生成（每期独立求解、seed 逐期推进、历史快照参与评分）；批量轮换可批量保存/导出（§7.4）；快照文件（v1.x）持续可读；快照恢复能力不可移除（数据安全）。
