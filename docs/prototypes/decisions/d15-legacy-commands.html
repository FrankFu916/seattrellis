Decision D15 · ledger §1 PYTHON_ONLY / INTENTIONALLY_REMOVED_V2 候选

遗留命令去留：init-demo / presets / workspace / desktop

v1 CLI 有 4 组命令在 v2 无对应实现（ledger PYTHON_ONLY）：init-demo（生成示例班级）、presets（规则预设）、workspace（启动工作台服务器）、desktop（启动桌面）。本决策确定各自去留；移除项需登记 INTENTIONALLY_REMOVED_V2（含理由、迁移方案、用户影响，ledger §0）。

判定标准：v2 功能覆盖（Tauri 壳替代 desktop、Rust app server 替代 workspace）→ 移除合理；有独立价值且无替代（示例数据/规则预设）→ 考虑保留并 Rust 化；移除必须附迁移说明。
A
全部移除（INTENTIONALLY_REMOVED_V2）
4 组命令全部登记移除；文档与迁移指南说明替代路径。
命令v1 用途v2 替代与影响
init-demo生成示例班级（名单/教室/规则）无替代——示例数据价值可被 D10 引导方案承接（若 D10 选示例班级则需 Rust 化）；当前影响：CLI 用户失去一键示例
presets规则预设模板（3 个）无替代——规则模板价值被 D3 句式模板承接（预置句式）；当前影响：JSON 预设文件不可用
workspace启动 Python 工作台服务器已替代——Rust app server（loopback HTTP）承担；影响：无（v2 已不同架构）
desktoppywebview 桌面壳已替代——Tauri 2 壳承担；影响：无（v2 final 移除 pywebview 为红线）
移除理由：workspace/desktop 有明确替代；init-demo/presets 的价值以 UI 形态（示例班级/句式模板）在 v2 呈现，命令行形态移除。
优势CLI 面最小、文档一致；与「v2 final 无 Python 运行时」红线完全一致；ledger 4 项 PYTHON_ONLY 一次清账。
代价命令行用户失去 init-demo/presets 的脚本化能力；若 D10 未选示例班级，示例数据价值完全丢失（需在 D10 中兜底）。
B
保留 init-demo（Rust 化）
init-demo 用 Rust 重写（生成示例班级目录），presets/workspace/desktop 移除。
命令决定理由
init-demo保留（Rust 化）示例数据对新手/演示/dogfood 有价值；Rust 化成本低（静态资产 + 目录写入）；与 D10「示例班级」可共用同一套资产
presets移除规则模板价值由 D3 句式模板承接
workspace移除由 Rust app server 替代
desktop移除由 Tauri 壳替代（v2 红线）
示例资产同时服务 CLI 与 UI（D10 选项 A）——资产复用是保留的最大理由。
优势示例数据成为共享资产（CLI + 引导 + dogfood）；一键体验完整流程；Rust 化成本可控（静态资源 + 校验）。
代价多一个 CLI 命令与测试面；示例资产需维护（与真实 fixture 数据隔离，防止误当真实数据）。
C
保留 presets（规则预设）
presets 用 Rust 化保留（list/show/export 规则预设），init-demo/workspace/desktop 移除。
命令决定理由
presets保留（Rust 化）规则预设对 CLI 自动化（脚本批量排座）有用；Rust registry 已有 goal 预设基础（goal_rules.rs），扩展为完整 preset 全集成本可控
init-demo移除示例价值由 D10 决策承接
workspace移除由 Rust app server 替代
desktop移除由 Tauri 壳替代（v2 红线）
presets 与 D3 句式模板的关系：UI 用句式模板，CLI 用 preset JSON——同一规则语义的两种入口。
优势CLI 自动化保留规则模板能力；Rust registry 基础已存在，扩展成本低；脚本用户迁移平滑。
代价preset 全集需要与 Python v1 全集逐项对账并补 golden（约 3 个预设）；CLI 面多一组子命令。
D
保留 workspace / desktop
workspace/desktop 命令保留（作为启动 Rust app server / Tauri 壳的命令别名），init-demo/presets 移除。
命令决定理由
workspace保留（别名）`seattrellis workspace` 作为启动 Rust app server 的命令别名，脚本/文档迁移零成本
desktop保留（别名）`seattrellis desktop` 启动 Tauri 壳（或提示用桌面应用），保持 CLI 入口习惯
init-demo移除示例价值由 D10 承接
presets移除由 D3 句式模板承接
注意：workspace/desktop 在 v1 是 Python 长驻进程入口；v2 作为别名指向 Rust 实现（行为兼容层）。
优势v1 脚本/文档的 `seattrellis workspace/desktop` 调用无需修改；CLI 入口习惯延续。
代价别名层增加维护与文档负担；「desktop 别名」与 Tauri 应用本身存在双入口困惑；与「移除 pywebview/Python 运行时」红线无冲突但语义重叠。
