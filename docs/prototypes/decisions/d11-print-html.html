打印版式设计规范（要点草案，细节待研究）：
  • A4 分页：每页固定行数，页内不切断座位块
  • 页眉：班级名 + 日期 + 期数 + seed（溯源）；页脚：页码 + 教室信息
  • 深色文字白底、无背景色依赖（黑白打印可读）
  • 无交互元素（无按钮/无菜单/无 hover 效果）
  • 隐私开关同样生效（public 模板匿名化）
「打印 HTML」与「网页 HTML」在导出菜单中为两个独立格式（v1 行为恢复）。
