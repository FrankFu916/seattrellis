Decision D11 · ledger §12 登记分歧

print-html 版式：保留独立 print 版式 vs 归一化 html + 打印样式

真实任务：教师导出「打印 HTML」贴墙。当前 v1 有独立的 print-html 输出（专为打印设计），v2 导出已把 print-html 归一化为 html + 独立打印样式表——需要拍板两种形态的去留。

背景事实（ledger §19.14 登记）：Rust export 已实现 print-html 归一化为 html（内容同一、样式区分）；这是 v1→v2 的已登记分歧，非实现缺口。选择「保留独立版式」需在 Rust 侧恢复独立渲染路径并补 golden；选择「归一化」则保持现状并更新导出契约文档。
A
保留独立 print 版式
导出格式列表里「打印 HTML」与「网页 HTML」是两种输出：打印版为 A4 分页优化、无交互元素。
📄 导出格式 · 2 种 HTML
<html> <!-- print.html -->
  <body class="print">
    <div class="page"> <!-- A4 分页 -->
      初二（3）班 座位表
      …（无交互、无菜单，纯排版）
</html>
<html> <!-- view.html -->
  <body>
    <nav>…</nav> <!-- 网页交互 -->
    <div class="seat-grid">…
</html>
导出面板显示两个独立格式：HTML（网页版）与 打印 HTML（A4 版式）。
与 v1 行为完全一致；需要 Rust 恢复 print 渲染路径 + 输出契约 golden。
优势与 v1 行为一致（教师已习惯）；打印版不受网页样式演化影响，版式可长期稳定；语义清晰。
代价两套 HTML 渲染路径需分别维护与测试；格式列表多一项，新手困惑「两种 HTML 区别」；golden 契约面扩大。
B
归一化 html + 打印样式
只有一种 HTML 输出；打印时通过 CSS @media print 呈现 A4 版式（现状）。
📄 导出格式 · 1 种 HTML
<html> <!-- seatmap.html -->
  <style>
    @media print {
      nav { display: none; }
      .seat-grid { page-break-inside: avoid; }
      @page { size: A4; margin: 12mm; }
    }
  </style>
  <nav>…</nav>      <!-- 屏幕：交互 -->
  <div class="seat-grid">…</div>
</html>
导出面板格式列表只有「HTML」；教师用浏览器打印对话框即可得到 A4 版式（v2 现状）。
保持 Rust 现有实现；只需在导出契约文档中明确「打印版式由 @media print 提供」。
优势单渲染路径，维护/测试面最小；格式列表简洁；与 Web 工作台「浏览器打印」心智一致。
代价与 v1 行为有差异（教师若按老习惯找「打印 HTML」需要适应）；打印版式受网页样式改动影响；浏览器打印对话框差异（页眉/边距）不可控。
