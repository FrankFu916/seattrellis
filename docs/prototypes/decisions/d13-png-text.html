PNG 文字渲染：渲染学生姓名 vs 无文字（纯座位图）

真实任务：教师把座位表导出 PNG 发微信群/家长群。当前 v1 PNG 无文字（纯色块）。是否在 PNG 上渲染学生姓名。

不可违反约束：PNG 是位图输出，字体渲染需引入光栅化路径（Rust 侧当前无）；隐私语义（public 模板匿名化）对位图同样适用；导出产物须经独立 validator 复核。
A
渲染学生姓名
PNG 座位块内绘制学生姓名（中文），家长群直接可读。

PNG 内文字随位图直接显示，任何看图软件可读；需 CJK 字体光栅化（约 1–2 周 + 字体资产）。
隐私开关对位图同样生效：public 模板 + 匿名化时名字打码为「学生 A/B/C」。
优势家长群/微信群直接可读，无需打开 PDF；PNG 是最通用格式，教师高频使用场景。
代价需要 Rust 字体光栅化路径（新依赖/实现面）；小尺寸座位块里长名（4 字+）可能溢出，需字号自适应。
B
无文字（纯座位图）
PNG 只有座位色块与区域标识（v1 现状），姓名需要配合 HTML/PDF 使用。
纯色块座位图：保留教室空间结构，但无法从图中识别人名——v1 现状。
保持现状：PNG 仅用于"教室结构示意"，名单以 HTML/PDF/XLSX 提供。
优势零实现成本；无字体依赖；隐私天然安全（无名字可泄漏）。
代价PNG 用途受限（发家长群需要配合文字说明）；教师需另用 PDF——v1 已知体验缺口。
