导出面板分层：快速导出菜单 vs 高级版式面板

真实任务：期中调座完成后，李老师要（1）把座位表导出 PDF 发家长群，（2）打印一份贴墙，（3）偶尔做带隐私设置的名单表。快速导出 vs 高级版式如何分层。

已冻结的能力（§5.6/§12）：8 种格式（svg/html/png/pdf/xlsx/docx/pptx + print-html）、teacher/public 模板、6 个隐私开关、页面方向/缩放/locale 参数全部已由 Rust export 实现并过独立 reader 验证；本决策只决定 UI 呈现分层。导出产物必须经独立 validator 复核。
A
快速导出菜单
工具栏一个「导出 ▾」按钮：直接列出格式，点击即导出（使用上次设置）；版式设置入口藏在菜单底部。

「上次设置」= 上次导出的模板/隐私/页面参数；未导出过则用默认（teacher 模板、隐藏成绩、A4 纵向）。
快速路径：一次点击完成；版式细节统一收在「版式与隐私设置」。
优势日常导出零摩擦（一次点击）；与 D1 上下文操作条的「下一步：导出」衔接自然；格式多时菜单可分组。
代价首次使用或换场景时需先进设置；「上次设置」的记忆语义需定义（按班级还是全局）。
B
高级版式面板
导出 = 打开完整版式面板：格式 / 模板 / 隐私开关 / 页面方向 / 缩放 / locale 全部可见，预览即时更新。

所有参数与 Rust export 契约一一对应（format/template/privacy/orientation/page_scale/locale）。
优势全部参数可见可调、预览即时；隐私开关显式呈现（§12.2 隐私语义）；首次/复杂导出不会漏设置。
代价每次导出多两步（打开面板 → 确认）；日常快速导出反而繁琐；面板字段多时新手压力大。
