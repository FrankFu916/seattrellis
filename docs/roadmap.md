# 产品路线图与演进规划（Roadmap）

[English](roadmap.md) · [简体中文](roadmap.md)

本文档阐述 **席序（SeatTrellis）** 当前已交付的能力与未来的持续优化方向。

---

## 🌟 1. v2.0.0 已交付能力

- **纯 Rust 高性能核心**：零 Python/Node.js 运行时依赖，提供命令行工具（`seattrellis`）与本地服务（`seattrellis_web`）；
- **现代化桌面客户端**：基于 Tauri 2 构建的跨平台原生应用；
- **全流程教师工作台**：向导式名单导入、教室绘制、偏好配置、多方案比对、可视化换座与多期轮换；
- **8 种格式本地导出**：支持 HTML、print-html、SVG、PNG、PDF、Excel、Word 与 PPTX；
- **本地优先与隐私保护**：全离线运算，公开版导出自动脱敏。

---

## 🚀 2. 未来演进与优化方向

1. **更强大的可视化布局编辑**：支持教室座位网格的框选、批量拖拽移动与异形排列向导；
2. **座次变动热力图与对比视觉化**：更直观呈现跨学期座次变动分布与同桌关系图谱；
3. **桌面端正式代码签名**：引入 macOS 公证与 Windows EV 代码签名，提升首次安装体验；
4. **极致可访问性与移动端适配**：进一步优化小屏平板与触屏黑板的交互体验。

---

## 🚫 3. 明确不纳入规划的范围

- **云端中心化数据存储与用户账号系统**：坚守本地优先底线，学生数据永不上传云端；
- **第三方商业遥测埋点**：坚决保护用户与学生的隐私。
