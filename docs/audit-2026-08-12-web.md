## 二、未修复问题清单（按严重度）

### 高

- **H1（已修，见 F2/F3/F4）** 竞态与输入丢失三类已闭环。同类残留：`applyEditorCommand`（撤销/重做/交换快速连点）依赖服务端 revision 冲突拒绝，客户端响应乱序时仅可能短暂显示旧状态后被冲突错误纠正——风险低，暂不改。

### 中

- **M1 导出预览匿名条件与后端一致性待验证**：`ExportPreviewDialog.tsx:93-96` 预览用 `template === "public" || privacy.anonymize` 决定是否显示假名。若后端对 `template=public` 强制匿名（隐私红线语义），用户在 public 模板下手动关闭 `anonymize` 后预览（真实姓名）会与导出文件不一致。需对照 seattrellis-server 导出请求处理确认（本次未读 crates）。
- **M2 三个手写 fetch 路径无 401 重试**：`downloadProjectGroupRegister` / `downloadProjectBundle` / `exportDraft`（`client.ts` 约 357-459、670-692 行）自行拼 fetch，未走 `fetchJson` 的 401 重引导。服务重启后这些操作会直接报错。建议抽取公共 blob 下载封装。
- **M3 画布键盘导航焦点不跟随**：`SeatingCanvas.tsx:370-387` 方向键移动选中（`onSelectChange`）但 DOM 焦点留在原座位，读屏/键盘用户失去位置感知。建议 `focus()` 到新座位 `<g>`。
- **M4 生成期间候选串行拉取**：`App.tsx:1182-1202` 逐个 `await fetchEditorState(candidate.candidate_id)`（5 候选 = 5 个 RTT）。可 `Promise.allSettled` 并行，超时预算不变。

### 低

- **L1 既有 React 警告**（非本次引入，stash 验证过）：`SeatingCanvasEditor` 框选测试触发 "Cannot update a component (`SeatingCanvasEditor`) while rendering a different component (`SeatingCanvas`)"。疑似渲染期 setState，建议单独排查 `SeatingCanvas` 渲染路径。
- **L2 大文件跨桥性能**：`desktop.ts` `saveBlobWithDialog`/`pickFileWithDialog` 用 `Array.from(bytes)`/number[] 传输整块字节，PDF/XLSX 等大导出会生成百万级元素数组。可考虑分块或 base64 字符串。
- **L3 全局 keydown effect 无依赖数组**（`App.tsx:429`）：每次渲染重挂监听；因闭包总是新鲜，无 stale 问题，仅微开销，可保留。
- **L4 拖动中 assignments 变化**：交换异步完成后若拖拽未结束，`dragRef` 内坐标基于旧 assignments，属边缘情况。
- **L5 `beforeunload` 本地化文本**：现代浏览器不显示自定义 returnValue 文本，提示仅剩系统文案，可接受。
- **L6 `workflowSteps` 导出**：作为 `WorkflowStep` 类型的值来源保留；无独立消费方，非死代码但可考虑内联。

### 安全（核查结论）

- **无 XSS 面**：全仓（非测试代码）`dangerouslySetInnerHTML` 出现 0 次；学生姓名/备注一律走文本渲染。
- **可信根校验无绕过**：`desktop.ts` `isTrustedRelativePath`（拒绝绝对路径/`\0`/`\`/`..`/盘符前缀）为输入级 UX 检查，后端 `trusted_relative_path` 是真正边界，客户端无绕过路径；`readTrustedFile` 只接受该函数过滤后的路径。
- **Token 不落 URL/日志**：`readDesktopSessionToken` 读 `?session=` 后立即 `history.replaceState` 清除并同步写入内存/sessionStorage；`console.error` 仅记录错误对象，不含名单/成绩。
- **localStorage 键面**：现存 `seattrellis-locale`（语言）、`seattrellis-first-run:v1`（引导条）、sessionStorage `seattrellis.desktop.session`（会话 token），均有用途；`seattrellis-theme` 已不存在（v1 遗留已清）。
