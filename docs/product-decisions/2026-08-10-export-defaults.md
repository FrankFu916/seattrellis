# SeatTrellis v2 — 导出默认值矩阵草案（D9 待研究项落地）

> 日期：2026-08-10
> 状态：**草案**——D9 决策（快速导出菜单）的默认值矩阵取值研究。默认值
> 须符合大多数教师场景；取值经 dogfood 验证后冻结（G-4），本文件为
> 候选默认值 + 验证计划。
> 关联：PD-D9-EXPORTPANEL、「上次设置」记忆语义、§12 导出契约。

## 1. 设计目标

- 90% 教师 90% 场景：点「导出 ▾ → 格式」即得到正确结果，无需进设置；
- 「上次设置」覆盖默认值（记忆语义见 §4）；
- 每个默认值都有理由，不拍脑袋（G-4）。

## 2. 默认值矩阵（候选，待 dogfood）

| 格式 | 默认模板 | 默认隐私 | 默认页面 | 默认输出名 |
|---|---|---|---|---|
| PDF | teacher | 隐藏成绩/备注/特殊需求；显示身高/视力 | **A4 横向**（可自选竖版）· 自动缩放 | `{班级}-座位表-{日期}.pdf` |
| HTML / 打印版 | teacher | 同上 | **A4 横向**（可自选竖版）· 自动缩放 | `{班级}-座位表-{日期}.print.html` |
| PNG | teacher | 同上 | 2x 分辨率 | `{班级}-座位表-{日期}.png` |
| XLSX | teacher | 同上 | — | `{班级}-名单-{日期}.xlsx` |
| DOCX | teacher | 同上 | A4 纵向 | `{班级}-座位表-{日期}.docx` |
| PPTX | teacher | 同上 | 16:9 | `{班级}-座位表-{日期}.pptx` |
| SVG | teacher | 同上 | — | `{班级}-座位表-{日期}.svg` |

### 关键取值理由

1. **默认模板 teacher（而非 public）**：教师导出首选是自用（贴墙/核对），
   public 是"发家长"场景——发家长时教师会选 public（菜单或上次设置）。
   理由需要 dogfood 验证：若实测教师主要导出是"发家长"，则默认应改为
   public 或做"上次导出模板"记忆。2026-08-12 dogfood 发现前端曾错误采用
   public 作为首次默认，导致所有格式把姓名替换为“学生”；已按本矩阵修正为
   teacher，并增加缺省字段回归测试。
2. **隐藏成绩/备注/特殊需求 + 显示身高/视力**：与 v1 teacher 模板语义一致；
   「显示身高/视力」是排座依据，教师自用需要。风险：贴墙版泄露身高信息
   （身高对同学可见）——**dogfood 重点验证项**，备选方案为 teacher 默认
   也隐藏身高。
3. **A4 横向 + 自动缩放（一页内最大化）**：横向宽度让座位格更大、姓名
   更清晰（贴墙实际需求）；用户可自选竖版；60 人教室先 A3 后分页
   （打印版式规范 §4.5/§6）。
4. **输出文件名含日期**：避免覆盖历史导出；不含 seed（文件名过长），
   seed 在内容页眉/详情里（G-3）。

## 3. 每种格式的默认用途（指导默认值选择）

| 格式 | 典型场景 | 频率估计 |
|---|---|---|
| PDF | 发家长群/打印 | 高 |
| HTML / 打印版 | 浏览器查看、贴墙、另存 PDF | 高（同一份自包含 HTML） |
| PNG | 微信群图片 | 中 |
| XLSX | 名单处理/存档 | 中 |
| DOCX/PPTX | 教学材料/汇报 | 低 |
| SVG | 分享/二次加工 | 低 |

> 2026-08-12 UI 收敛：基础 `html` 与 `print-html` 对普通用户用途重叠，目录只
> 展示一个“HTML / 打印版”入口并使用 `print-html`。底层仍接受 `html`，用于
> CLI/历史调用兼容，不改变冻结的 8 格式传输契约。

## 4. 「上次设置」记忆语义（候选，待 dogfood）

- **全局记忆 + 班级可覆盖**：最近一次导出参数（模板/隐私/页面/格式）
  全局记住；某个班级手动改过后，该班级以班级设置优先。
- 记忆键：`last_export_{format}` 的模板/隐私/页面；班级覆盖键：
  `class_{id}_export_defaults`。
- 存储位置：Rust 端（项目目录内 .seattrellis 元数据或用户配置目录），
  **不是浏览器 localStorage**（跨端一致，桌面/Web 同体验）。
- 重置入口：「版式与隐私设置」面板内「恢复默认」按钮。

## 5. dogfood 验证计划（G-4）

| 验证项 | 方法 | 通过标准 |
|---|---|---|
| 默认模板 teacher vs public | 10 名教师 20 次真实导出记录 | ≥80% 首导出无需改模板 |
| 身高默认显示 | 贴墙场景回访 | 无"身高被同学看到"抱怨且 ≥80% 保留显示 |
| 默认文件名 | 连续导出 3 次 | 无覆盖、无困惑 |
| 「上次设置」记忆 | 跨会话导出 | 第二次导出直接用上次参数（≥80%） |
| 60 人教室 | 打印/PDF 导出 | 自动分页正确、座位行不切断 |

## 6. 冻结流程

1. 本草案经产品负责人评审（可调整取值）；
2. M5 实现按候选默认值落地；
3. dogfood 按 §5 执行，结果记录后冻结默认值（G-4）；
4. 冻结值写入导出契约文档（§12）与 capability 目录（§4.3）。
