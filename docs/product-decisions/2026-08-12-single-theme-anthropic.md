# SeatTrellis v2 — 主题收敛与视觉风格决策（Anthropic 基准）

> 日期：2026-08-12
> 状态：**已决策，风格基准确定**（像素 token 随 dogfood 微调，G-4 冻结）
> 决策人：产品负责人（席序 v2）
> 依据：产品负责人对阶段 B 视觉不满意、要求"只留一套最好的主题、
> 帮用户做决定"；本记录修订 `2026-08-10-ui-design-direction.md` 的
> 主题策略（原为 5 套主题 + 选择器），视觉哲学四支柱与反模式红线
> 不变。

## 1. 决策内容

1. **主题系统收敛为一套**：删除 calm/native/focus/paper 四套视觉主题
   与页头主题选择器；只保留**一套设计 + 跟随系统明暗**（浅色/深色由
   `prefers-color-scheme` 决定，无任何用户可见的主题选择）。理由：
   主题是纯产品噪音，用户应把决定精力留给排座本身（专业简洁，
   G-6）。
2. **风格基准 = Anthropic 设计系统**（产品负责人指定；色板与字体经
   实证抓取 anthropic.com 生产 CSS，2026-08-12）：
   - **命名体系**：采用其 swatch 命名（slate/ivory/clay/cloud/
     olive/coral/sky/heather），token 即语义；
   - **暖色板**：象牙白底、石板墨字、陶土强调、云灰边框；
   - **衬线标题 + 无衬线正文**（其 Tiempos Text / Anthropic Sans
     的分工），中西文分栈。
3. **主操作按钮 = 墨色（slate-dark）**，陶土（clay）仅用于链接/激活/
   聚焦态——与 Anthropic 官网 CTA 一致，且避免陶土橙红与"违规红"
   语义撞色。

## 2. 色板映射（浅色；深色为同系反转）

## 3. 字体策略（延续 D12：不打包字体）

- **标题**（--font-display）：`"Tiempos Text", Georgia, "Times New Roman",
  "Noto Serif SC", "Songti SC", "SimSun", serif`——西文优先 Georgia
  （macOS/Windows 自带），中文走宋体系（Songti/Noto Serif SC/SimSun）；
  负字距从 -0.02/-0.035em 放宽至 -0.01em（衬线不适配紧排）。
- **正文**（--font-ui）：系统无衬线栈（-apple-system/Segoe UI/Noto
  Sans SC/Microsoft YaHei）。
- 等宽（ui-monospace）仅用于代码/JSON/seed（G-3）。

## 4. 半径与层级

- 圆角收敛 6/10/14px（比原 8/12/16 更方、更 Anthropic）；
- 阴影带暖色调（rgb 50 42 30）；层级仍以留白与字重为主。

## 5. 证据与验收

- 146 vitest 全绿、typecheck、vite build；浏览器验证：页头仅剩语言
  选择器、暖色板与衬线标题生效（截图存 /tmp 供目检）。
- **待 G-4 dogfood**：像素值（色相微调/圆角/字号）随目检修订后冻结。
- 设计方向文档 §3/§5 的主题相关条目以本记录为准（主题选择器删除、
  单一主题 + 系统明暗）。

## 6. 工作台重设计第二轮（真实主流程 dogfood）

本轮把参考对象拆成三层，避免把营销站视觉直接套到生产力工具：

1. **Anthropic 官网**：只吸收暖象牙底、墨色主操作、陶土点缀、大留白；
2. **Claude.ai 公共产品壳**：吸收单一主任务、克制卡片、低噪音工具栏；
3. **Apple HIG**：以层级、一致反馈、可恢复操作、键盘与可访问性作为交互
   下限。衬线体只用于页面标题与少量品牌文字；名单、表单、按钮和座位数据
   继续使用系统无衬线体。Anthropic 官网的营销排版不作为数据密集 UI 模板。

真实浏览器依次走通名单 → 教室 → 规则 → 生成 → 座位编辑后，完成这些修订：

- **壳层去伪上下文**：页头删除硬编码“初二（3）班”和重复学生数，只保留
  品牌、本地状态与语言；当前班级/临时工作台由上下文栏唯一呈现。
- **班级空状态修复**：本地服务已连接但最近班级为空时不再显示空白区域；
  显示可行动说明。侧栏不再暴露项目绝对路径，只显示“已保存到本机”。
- **默认路径减负**：已有名单直接展示姓名/学号；成绩、身高、视力、特殊需求、
  备注收进“排座资料”；CSV/Excel 导入收进可展开区。能力没有删除，默认页面
  不再要求用户先处理非核心资料。
- **双重选中降噪**：班级/临时工作台属于上下文选中，班级内容属于页面选中，
  两者改用不同视觉层级，不再出现两个同强度陶土高亮。
- **生成后首屏修复**：原 CSS 自动排版把候选比较占满整行，座位画布被推到
  首屏以下并留下大片空白；改为首行“微调 / 座位画布 / 诊断”，候选比较下沉
  到第二行。座位画布获得最大宽度。
- **新手引导精简**：有效名单自动记为第一步完成；当前步骤有独立焦点态；
  窄窗口改为单列标题 + 横向步骤，不挤压主操作。

验证：React **148 vitest**、`tsc -b`、Vite production build 全绿；真实
Rust 本地服务浏览器完成 5 候选生成，座位画布、未入座与诊断同屏，页面无
水平溢出。此轮仅改 React 展示/输入级状态，不新增 TS 业务规则、不改变 Rust
contract，不提升 parity ledger 状态。

## 7. 座位主舞台与文案准则修订（第三轮）

产品负责人再次指出座位窗口、文字和格子过小。浏览器实测确认问题不只是
字号：`.seating-holder` 的 `max-content` 让 SVG 长期停在 430px 内在宽度，
同时三列工作台把核心座位表限制在约 500px；这是布局错误，不应要求用户
反复点“放大”补偿。

- **座位表是页面主舞台**：生成后第一行由座位画布独占全宽；微调控制与
  未入座/诊断下沉到第二行，候选比较在第三行。默认视图即清楚可读，不把
  “调整缩放比例”留给用户决定。
- **画布真实铺满容器**：holder 改为 `width: 100%`，座位块随可用宽度自然
  放大；保留 430px 最小宽度供窄屏横向滚动。
- **一键专注查看**：工具栏提供“专注查看”，以完整窗口承载同一编辑状态；
  点击遮罩或 Esc 退出。没有另建第二份画布状态、规则真相或 undo 栈。
- **Anthropic 文艺感的使用边界**：页面标题/品牌可用衬线体和编辑式短句；
  控件、名单、座位姓名保持系统无衬线。句子先说明下一步及结果，不拟人化、
  不堆情绪词、不用诗性命名掩盖功能。克制与准确比“像 Claude”更重要。
- **导出默认值纠错**：前端原默认格式 ID 为不存在的 `print`，真实契约是
  `print-html`；已直接修正，不让用户通过重新选择格式来绕过程序错误。

浏览器使用真实 Rust 服务生成 5 个候选方案验收：常规 1280px 视图座位表
约占 970px，可首屏读取中文姓名；专注视图占窗口主体且 Esc 可恢复。此轮
仍只新增展示状态与输入级默认值，不扩展 TS 规则/合法性判断。
