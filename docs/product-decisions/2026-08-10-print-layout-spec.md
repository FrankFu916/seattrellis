# SeatTrellis v2 — 打印版式设计规范草案（D11 待研究项落地）

> 日期：2026-08-10
> 状态：**草案**——D11 决策（独立 print 版式 + 精心设计）的版式细节研究。
> 本文件冻结打印版式契约；M5 实现按此渲染。与 UI 设计方向草案
> （2026-08-10-ui-design-direction.md）一致：深色文字白底、无背景色依赖、
> 无交互元素、语义克制。
> 关联：PD-D11-PRINTHTML（独立 print 版式）、G-1（去术语化）、
> G-3（复现信息可查）、隐私开关（§12.2）。

## 1. 用途与目标

「打印 HTML」是教师**物理贴墙/分发**的座位表：A4 打印、黑白可读、无网页
交互。它和「网页 HTML」是两种输出（v1 行为恢复，D11 决策）；本规范定义
打印版式的全部细节。

验收目标（真实任务）：教师打印后能① 一眼找到任一学生的座位；② 确认
日期/期数/seed 溯源；③ 隐私设置生效（public 模板无成绩/备注/姓名匿名）。

## 2. 页面与分页

| 项 | 规范 |
|---|---|
| 纸张 | A4（210×297mm）；纵向为默认，横向可选（orientation 参数，与 PDF 对齐） |
| 边距 | 上下 12mm、左右 14mm（避免打印机不可打印区，最小 5mm 保险） |
| 分页 | 每页固定行数：整行座位组不跨页切断；页内从上到下：页眉 → 座位表 → 页脚 |
| 页数 | 多页时每页重复页眉与页脚；座位表跨页时页脚注明「续第 N 页」 |
| 缩放 | page_scale 0.5–2.0（与 PDF 参数语义一致），默认 1.0 = 一页内完整呈现 30 人教室 |

## 3. 页眉（每页顶部）

```
┌────────────────────────────────────────────┐
│ 初二（3）班 · 座位表           2026-03-17   │   ← 左：班级名+用途；右：日期
│ 第 3 期 · seed 168996 · 教学楼 302          │   ← 溯源行（G-3）
└────────────────────────────────────────────┘
```

- 第一行：班级名 + 「座位表」（黑体 14pt 级）；右侧日期（YYYY-MM-DD）。
- 第二行（溯源）：期数、seed、教室；10pt 级灰阶（打印仍可读，#444 级）。
- 溯源行**不省略**（§7.6 复现性：seed 必须可查、可导出）。

## 4. 座位表

- **表格语义**：排 × 列座位网格；第 1 列排号（第 1 排…），表头列号
  （1 2 3 4）——教师按"第 X 排第 Y 列"定位（与画布 seat_id RrCc 一致）。
- **单元格**：学生姓名（13pt 级黑体）+ 学号（9pt 级灰阶，teacher 模板）；
  锁定座位加实心边框标记（不依赖颜色：黑白打印可辨）；空座显示「空座」
  或留白（模板决定）。
- **固定/锁定表达**：锁定座位边框加粗 + 角标「锁」（文本标记，非颜色）。
- **区域标注**：教室结构（讲台/门/窗）以文字标注在网格四周——「讲台 ↑」
  在首排上方；「门」在相应列侧。**不画图形图标**（打印线条不可控）。

## 5. 页脚（每页底部）

```
────────────────────────────────────────────
第 1 / 2 页 · 生成于 2026-03-17 10:24 · SeatTrellis 0.1.0
```

- 页码 + 生成时间戳 + 版本号（溯源完整性）；9pt 级灰阶。

## 6. 隐私生效（§12.2，与所有导出格式一致）

| 开关 | 打印版式行为 |
|---|---|
| hide_scores / hide_notes / hide_special_needs | 单元格不渲染对应内容（当前渲染模型本就不含，保持） |
| anonymize | 姓名替换为「学生A/B/C…」（与 PNG/PDF 打码语义一致，G-1 通俗化） |
| show_height / show_vision | teacher 模板默认显示；public 默认隐藏 |

**红线**：打印版式不得绕过任何隐私开关；public 模板导出后必须零真实姓名
泄漏（独立 validator 复核——与 §19.11 的 204 项零泄漏同一标准）。

## 7. 与「网页 HTML」的差异矩阵（契约）

| 维度 | 打印 HTML | 网页 HTML |
|---|---|---|
| 输出目的 | 物理打印 | 屏幕浏览/分享 |
| 交互 | 无（无按钮/菜单/hover） | 有（导航/缩放/下载） |
| 布局 | A4 分页固定 | 响应式流式 |
| 样式 | 黑白优先、灰阶、无背景图 | 完整品牌色 |
| 时间戳 | 页眉/页脚固定 | 页面内元数据 |
| 输出契约 | 本规范 | 现有 html 契约 |

两条渲染路径各自独立实现与独立 validator 结构验证（§19.18 已定）。
