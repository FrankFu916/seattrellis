# SeatTrellis v2 — 打印版式设计规范（D11 待研究项落地 · 修订版）

> 日期：2026-08-10（初版）；**2026-08-12（按实际需求修订两次）**
> 状态：**草案**——D11 决策（独立 print 版式 + 精心设计）的版式细节研究。
> **修订要点（产品负责人 2026-08-12）**：① 打印版式必须切合贴墙/分发的
> 实际使用——一页纸内座位最大化、姓名大字、字号统一按最长姓名自适应、
> 标注教室结构（讲台/过道/窗/门）；不需要学号、锁定等排座态装饰。
> ② **默认横版（A4 横向）**，用户可自选竖版；③ **可配置选项尽可能多**
> （§4.5 清单）。本规范同时约束 print-html 与 PDF（两者都是"打印/贴墙"
> 用途，版式一致）。
> 关联：PD-D11-PRINTHTML、G-1（去术语化）、G-3（复现信息可查）、
> 隐私开关（§12.2）、UI 设计方向草案。

## 1. 用途与目标（修订）

「打印 HTML」/「PDF 座位版」是教师**打印后贴墙或分发，供同学查看**的
座位表。真实使用场景决定版式：

- 同学要能在**一页纸**上快速找到自己的名字；
- 姓名要大、清晰，站在一米外可读；
- 教室结构（讲台/过道/窗/门）帮助定位；
- 不需要学号、锁定标记、成绩等排座工作态信息（那是 teacher 自用视图，
  不是贴墙版）。

验收目标（真实任务）：30 人标准教室打印后，同学 3 秒内找到自己的座位；
姓名在 1 米外可读；一页纸完整呈现。

## 2. 版面原则（修订核心）

1. **一页纸优先**：默认输出必须在**一张 A4 内完整呈现全部座位**。座位
   大小 = 一页可用面积 ÷ 网格行列数（最大化），不预先固定字号/座位尺寸。
   60 人以上大班若一页放不下，才允许分页（§6），且每页仍是"最大座位 +
   大字姓名"。
1b. **默认横版（A4 横向）**：横向可用宽度更大（273mm），座位格更宽、
   姓名更大——是贴墙场景的最优默认。**用户可自选竖版**（可配置项，
   §4.5）。
2. **姓名大字、字号统一**：全班使用**同一个字号**，由**最长姓名**决定——
   字号 = 使最长姓名在座位格内正好放下（两边各留 ≥2mm 边距）的最大值；
   上限 24pt（超过则截断姓名并提示，见 §5）。同班同学姓名必须同字号
   （统一性 > 个性化）。
3. **座位最大化**：无固定边距/行高浪费；页眉/页脚精简（只保留溯源必需
   行），把面积让给座位区。
4. **只放姓名**：座位格内**只有学生姓名**（默认）。学号/锁定/身高/成绩
   一律不渲染（teacher 自用信息走网页版/名单导出）。
5. **结构标注**：讲台/过道/窗/门以文字标注（黑白可辨），不画图形图标。

### 3.1 页眉（一行，最小化）

- 左：班级名 + 「座位表」；右：日期。字号 ≤11pt 灰阶（#444 级）。
- **不占第二行**（溯源信息下移到页脚，面积让给座位）。

### 3.2 座位区（主体，最大化）

- **网格**：按布局的行列数（含过道列）铺满可用面积；方格或表格均可
  （以渲染最简单且视觉一致为准——统一用表格行/列实现）。
- **单元格**：仅姓名，水平垂直居中；姓名不换行（字号自适应保证放得下）。
- **过道**：布局中的过道列/行以空格或虚线列呈现，并标注「过道」；
  过道从布局语义推断（见 §4）。
- **锁定/禁用座**：禁用座显示为空格（不画叉，保持版面干净）；锁定座
  不显示任何标记（打印版是结果视图，不是编辑视图）。

### 3.3 结构标注（文字，黑白可辨）

| 结构 | 标注方式 | 来源 |
|---|---|---|
| 讲台 | 首排上方居中「讲台 ↑」 | 布局 zone=front 或 near_platform 首行 |
| 过道 | 列间隙标注「过道」或虚线列 | 布局列间隙（§4 推断） |
| 窗 | 网格右侧「窗 ←」 | seat.near_window |
| 门 | 网格左侧「门 →」 | seat.near_door |

标注字号 ≤10pt 灰阶；不画图形（打印线条/图标不可控，文字最稳）。

### 3.4 页脚（一行溯源，G-3）

`第 N 期 · seed 168996 · 第 1/1 页 · SeatTrellis 0.1.0`（≤9pt 灰阶）。
seed 必须可查可导出（§7.6）——放页脚不占版面。

## 4. 字号与座位大小算法（修订核心）

给定：A4 纸张（默认**横向**：宽 297mm × 高 210mm；竖版 210×297mm），
扣除边距（12mm 上下 / 14mm 左右，可配置）后为可用面积；班级布局
rows × cols（含过道间隙）。

1. **可用面积**：宽 W、高 H（mm）。
2. **网格占用**：cols 列 + 过道列数（a 列过道按 0.5 列宽计）；rows 行。
   单元格宽 w = W ÷ (cols + 0.5a)，高 h = H ÷ rows。
3. **座位格**：格内可用 = (w − 4mm) × (h − 4mm)（两侧各 ≥2mm 边距）。
4. **字号**：全班最长姓名的宽度 ≈ 字符数 × 字号 × 0.95（中文近似）；
   字号 = min(格内可用宽度 ÷ (最长姓名宽系数 × 字数), 24pt 上限)。
   若 24pt 仍放不下（超长姓名），按 24pt 渲染并在**页脚**提示
   「姓名超过版面宽度，已截断：XXX」。
5. **统一性**：同班所有姓名用同一字号（步骤 4 的计算结果）。

校验示例：5×4 教室 20 人、最长姓名 4 字 → 格宽 ≈ (182−28)÷4 ≈ 38mm，
字号 ≈ 38−4 ÷ (4×0.95) ≈ 8.9mm ≈ **25pt → 上限 24pt**——一页放 20 个
24pt 名字 ✓。60 人 10×6 教室 → 格宽 ≈ 154÷10 ≈ 15mm → 字号 ≈ 11÷3.8 ≈
3mm ≈ 8.5pt——偏小，触发 §6 分页策略评估（或横向）。

## 4.5 可配置选项（默认值 + 用户可调，D9 原则"默认符合大多数、可自定义"）

| 选项 | 默认 | 说明 |
|---|---|---|
| 方向 | **横版（A4 横向）** | 用户可自选竖版 |
| 纸张 | A4 | 可选 A3 / Letter（A3 支持超大班级一页） |
| 缩放 | 自动（一页内最大化） | 手动 page_scale 0.5–2.0 覆盖自动 |
| 字号策略 | 自动（按最长姓名） | 手动指定字号覆盖（含"字号上限"调整） |
| 显示学号 | 关 | 开 = teacher 自用核对（姓名+学号） |
| 结构标注 | 讲台/过道/窗/门 全开 | 各结构独立开关 |
| 页眉内容 | 班级名 + 日期 | 可加/减（含期数、seed 开关——seed 默认开，G-3） |
| 网格样式 | 方格 | 表格线（无边框）可选 |
| 颜色 | 黑白（灰阶） | 彩色可选（teacher 自用） |
| 模板 | teacher | public（含 anonymize 语义） |
| 隐私 | 6 开关（同全部导出格式） | hide_scores/hide_notes/hide_special_needs/anonymize/show_height/show_vision（后两项打印版默认忽略，见 §5） |
| locale | zh | en 等 |

**原则**：默认值贴合 90% 场景（横版一页大字）；可配置项覆盖剩余场景且
与 Rust export 契约一一对应（orientation/paper_size/page_scale/margin_mm/
locale/template/privacy），UI 只做输入级校验，语义由 Rust 端冻结。

## 5. 隐私生效（§12.2，与所有导出格式一致）

| 开关 | 打印版式行为 |
|---|---|
| anonymize | 姓名替换为「学生A/B/C…」（打码语义与 PNG 一致） |
| hide_scores / hide_notes / hide_special_needs | 本版式本就不渲染成绩/备注/需求（无内容可隐藏，语义保持） |
| show_height / show_vision | **打印版式忽略**（贴墙版不需要身高/视力——按 §2.4 只放姓名） |

**红线**：public 模板 + anonymize 后零真实姓名泄漏（独立 validator 复核，
与 §19.11 的 204 项零泄漏同一标准）。

## 6. 分页策略（大班，修订）

- **默认一页内最大化**（§4 算法）；不主动分页。
- 60 人以上且字号 < 8pt（不可读阈值）时：
  - 优先尝试 **A3 纸张**（可配置，格宽增大）；
  - 再尝试**手动缩放**（page_scale 调整）；
  - 仍不足 → 分页（每页行数固定、整行不切断、页脚页码 + 每页重复
    页眉与结构标注）。
- 分页是例外路径，默认输出永远尝试一页。

## 7. 与「网页 HTML」/「名单导出」的差异矩阵（契约）

| 维度 | 打印 HTML / PDF 座位版 | 网页 HTML | XLSX 名单 |
|---|---|---|---|
| 目的 | 贴墙/分发，同学查看 | 屏幕浏览 | 数据/存档 |
| 内容 | 仅姓名 + 结构标注 | 完整信息（含学号/锁定等） | 全字段 |
| 布局 | 一页 A4 最大化 | 响应式 | 表格 |
| 字号 | 统一、按最长姓名自适应 | 常规排版 | 常规 |
| 交互 | 无 | 有 | 无 |
| 输出契约 | 本规范 | 现有 html 契约 | 现有 xlsx 契约 |
