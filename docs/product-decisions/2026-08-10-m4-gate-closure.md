## 4. M4 → M5 边界

**M4 结束（本声明）**：产品决策、交互契约、设计方向、事务语义全部冻结或
有明确归属；技术线收尾完成。

**M5（alpha）开始前提**（按计划 §8.1 alpha.1）：
1. M5 实现计划（批 1 融合形态 → Rust contract + React E2E 逐项验收）；
2. 打印版式规范/导出默认值按草案落地并 dogfood；
3. React 规则消费切换 Rust registry（M6 删除项的前置）；
4. Tauri 壳能力补齐（D14 三入口文件选择、平台自适应、减动效偏好）。

**M4 明确不承诺**（§7.8，不进入 v2 scope）：插件/脚本扩展、云同步、
账号系统、多人协作、远程 AI、云端组织管理、通用会场/极坐标布局、
无限格式。
