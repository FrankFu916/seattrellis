## 1. 决策内容

1. **不引入液态玻璃 / 毛玻璃拟态**：维持 M4 冻结方向。§7 反模式红线
   （装饰性玻璃拟态/毛玻璃）不动，产品不整体模仿 Apple Liquid Glass；
   不做渐变按钮、不做装饰动效、不加反射高光。
2. **平台主题策略 = 单一跨平台主题**：三平台同一套视觉（跨平台中性），
   平台差异仅限惯例层（快捷键、系统对话框、macOS 窗口毛玻璃能力
   降级），不为各平台维护多套设计系统。
3. **产品负责人对 M5 阶段 B 的视觉质量不满意（操作逻辑无问题）**：
   本轮按设计方向 §8.2 启动像素级 token 首轮制定，目标是提升视觉
   品质（可读性/层级/对比度），不改变信息架构与交互。

## 2. 首轮像素级 token 制定（2026-08-12 执行）

### 2.1 字号刻度（tokens.css 新增 --text-2xs … --text-2xl）

| token | 值 | 用途 |
|---|---|---|
| --text-2xs | 0.6875rem (11px) | 说明文字、步骤号、徽章 |
| --text-xs | 0.75rem (12px) | 表头、大写眉题 |
| --text-sm | 0.8125rem (13px) | 次级正文、chip |
| --text-md | 0.875rem (14px) | 正文、按钮（默认） |
| --text-lg | 0.9375rem (15px) | 强调正文 |
| --text-xl | 1rem (16px) | 面板标题、品牌 |
| --text-2xl | 1.125rem (18px) | 区块标题 |

**原则（写入 token 注释）**：UI 文案不得小于 11px；10px 级仅保留给
viewBox 缩放的画布字形。全 app.css 规范化：原 0.58–0.85rem
（≈9.3–13.6px）的约 120 处字号收敛为 11/13/14px 三级为主；字重
750→650、760/800→700（去噪音）；画布 SVG 文字（座位名 13px、
空座 11px、行标 8px、讲台 11px）按 viewBox 语义保留。

### 2.2 默认主题色板精修（含深色主题同步）

- 文字加深：--text #20232a→#1c2027、--muted #69707d→#565d69
  （对比度提升，WCAG AA 余量更大）；
- 边框加深：--border #e1e4e9→#dde0e6、--border-strong →#b9bfc9；
- 强调色 #4361ee→#3457d5（去除高饱和 SaaS 霓虹感，§7 反模式
  "千篇一律 SaaS 紫/蓝"类规避），--accent-hover/--accent-soft 同步；
- 圆角 --radius-large 18→16px（克制）；
- 深色主题对应调整（--muted/--accent/--surface-tint 等）。

### 2.3 控件与布局

- 输入/选择控件高度统一 36px（原 30–34px 混杂）；
- 侧栏导航项 min-height 38→40px、padding 8px 10px；
- 面板留白加大（panel-heading 26/24/20px、panel-content 20px）；
- 内容列 max-width 1080→1200px（1440 屏利用率）。

- 为 macOS/Windows 维护双套视觉主题（单一跨平台主题）；
- 本次不改变任何信息架构、交互逻辑与语义色含义（红=违规/黄=建议/
  绿=满足/紫=锁定/青=选中）。
