SeatTrellis visual directions

这次不是换皮，而是换产品世界。

每个模板都使用不同的信息架构、控件隐喻、视觉密度和平台气质。它们仍是静态页，只用于选择方向。

怎么比较 Apple 看亲和力，Fluent 看桌面端正式感，Material 看移动/触控，GNOME/KDE 看 Linux 原生感，Swiss 看打印与教务，DOS 看极简键盘流，Carbon 看数据密度，Calm Hybrid 看 SeatTrellis 自有品牌。

Apple-inspired

大标题、半透明材质、柔和深度、内容优先。适合老师打开后“没有压力”。

  • 空气感和留白最大
  • 适合导出预览和轻操作
  • 复杂管理功能容易显得太散
查看模板

Linear / Notion

SaaS 工作台、命令菜单、文档块、数据库表。像项目管理工具，不像系统窗口。

  • 项目和规则管理最清楚
  • 适合长期工作台
  • 座位画布需要避免过于表格化
查看模板

Muji

温暖纸品、朴素目录、生活工具感。比 Swiss 更柔软，比 Apple 更低调。

  • 亲切、耐看、少技术感
  • 适合老师和打印场景
  • 需要补足现代交互反馈
查看模板

Windows Fluent

窗口标题栏、命令栏、左侧导航、Mica/Acrylic 气质。更像正式桌面软件。

  • Windows 独立安装包适配好
  • 功能入口清楚
  • 品牌感略偏微软生态
查看模板

Android Material

手机壳、tonal surface、chip、FAB、触控优先。和桌面工作台非常不同。

  • 移动端和触屏最好
  • 操作按钮非常明显
  • 桌面专业感不如 Fluent/Carbon
查看模板

GNOME Adwaita

Headerbar、split view、原生 GTK/libadwaita 卡片。简洁、克制、Linux 感强。

  • 原生应用感明显
  • 可访问性和一致性好
  • 视觉惊艳程度中等
查看模板

KDE Breeze

菜单栏、工具栏、状态栏、可配置感。经典 Linux 桌面软件世界。

  • 工具属性强
  • 适合高级用户
  • 普通老师可能觉得“工程味”重
查看模板

Swiss Print

海报式标题、严密网格、黑红两色、纸张感。像排版精良的教务表。

  • 打印导出最自然
  • 风格强烈且耐看
  • 交互控件需要另设计
查看模板

DOS / Terminal

纯文本、ASCII 座位图、键盘优先。极端复古，但功能效率很高。

  • CLI 精神最强
  • 低资源、离线感明显
  • 不适合作为默认网页
查看模板

Carbon Enterprise

高密度数据表、深色面板、企业级诊断。适合管理者和重数据场景。

  • 数据可读性强
  • 性能/基准/审计页合适
  • 对老师日常偏冷
查看模板

Calm Hybrid

温和绿色、画布+检查器、自有品牌。不是平台仿制，而是 SeatTrellis 风格。

  • 最适合作为正式产品方向
  • 兼顾温和与专业
  • 可以吸收各平台优点
