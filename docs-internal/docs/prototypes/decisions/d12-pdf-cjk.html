PDF CJK 字体 — 融合方案：系统字体智能引用（无嵌入、无 fallback）

真实任务不变：PDF 座位表必须正确显示中文姓名。生成端枚举系统字体按质量优先级选取（一定有可用字体），PDF 按字体名引用（体积 0）；查看端缺字体时由 PDF 查看器自动替换；选中字体质量偏低时导出警告，不阻断。

决策依据（评审修正）：任何可运行 GUI 的设备必有 CJK 字体；PDF 查看器（Acrobat/预览/手机阅读器）缺指定字体时按 Unicode 自动替换——v1 的座位号 fallback 是生成端缺陷，本方案从根源消除。不嵌入、不 fallback 座位号。安装包 5–20MB gate 无压力。
